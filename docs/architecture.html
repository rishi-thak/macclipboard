Clipboardopt Architecture

A background Mac app that keeps your last 10 text copies and, on Cmd+Opt+V in Safari, pastes the one that fits the field you're in. Decides on your Mac whenever it can, and asks Jev only when the field is unclear.

Decision table

Every case has an outcome. Jev only supplies the yes/no answers; these rules live in code.

SituationResult
No text field focusedKey passes through untouched
Plain Cmd+V, with anything on the clipboard (image, file, text)Never touched: stock macOS paste
Smart paste while an image or file is on the clipboardPastes the text, then puts the image back byte for byte
Job application, field is a known kind (Email, Phone, LinkedIn…), profile has itPaste profile value
Same as above, but you copied that kind in the last 30 secondsPaste your fresh copy
Not a job application, known kind, exactly one copy of that kindPaste it
Several matching copies, or the label is unclear ("How can we reach you?")Ask Jev
Jev: one candidate above 0.7, the rest lower, "anything fits" above 0.7Paste the winner
Jev: no candidate above 0.7, two above 0.7, or "anything fits" unclearPanel, best guess first
Jev: "anything fits" below 0.3Panel, nothing highlighted
Jev request fails or times outPanel, with an error note

What Jev sees (draft)

One request per unclear field. Each candidate gets its own question with the value written in, and the job-application question is asked only when the page isn't cached yet. Profile values are shortened here.

{
  "model": "jev-latest",
  "state": {
    "page":  { "url": "jobs.ashbyhq.com/acme/…/application",
               "title": "Software Engineer · Acme" },
    "field": { "label": "Where can we see your work?",
               "placeholder": "https://", "type": "url" },
    "candidates": [ "linkedin.com/in/…", "github.com/…",
                    "https://example.dev", "me@example.com" ]
  },
  "questions": {
    "fits_0": { "type": "noul", "instructions":
      "Does the user want to paste \"linkedin.com/in/…\" into `field`?" },
    "fits_1": { "type": "noul", "instructions":
      "Does the user want to paste \"github.com/…\" into `field`?" },
    "…": "one per candidate",
    "anything_fits": { "type": "noul", "instructions":
      "Does any value in `candidates` belong in `field`?" },
    "is_job_application": { "type": "noul", "instructions":
      "Is `page` a job application form?" }
  }
}

Swift modules

Same setup as SSClipboard and gitviz: Swift 6, Swift Package Manager, AppKit, no outside libraries, started at login.

FileJob
HotKeyManagerCatches Cmd+Opt+V (same event-tap approach as SSClipboard)
ClipboardWatcherChecks the change counter, skips password-manager and non-text copies
ClipboardHistoryNewest 10 text items, no duplicates, saved to disk
ItemClassifierTags email, phone, URL, LinkedIn on your Mac
ProfileLoads your preset values from a file outside the code
FieldReaderAccessibility: focused field's label, placeholder, type; Safari URL and title
ContextDetectorJob-site list plus a saved answer per page
SmartPasteEngineThe decision table above
JevQuestionsAll question wording and thresholds in one place
JevClientCalls the TypeSafe API, reads JEV_API_KEY
PasterSets the clipboard, sends Cmd+V, restores the old clipboard
HistoryPanelThe picker window, keyboard-first
